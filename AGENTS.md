# Rules for AI Agents

## Reference Project

The author maintains several dprint WASM plugins.
These plugins only delegate formatting work to upstream crates.

- **Primary Reference**: [kachick/dprint-plugin-typstyle](https://github.com/kachick/dprint-plugin-typstyle)

The author makes changes to `kachick/dprint-plugin-typstyle` first, and then applies them to the other plugins.
This repository should follow the codebase and patterns of `dprint-plugin-typstyle`.
When in doubt, refer to the implementation in [kachick/dprint-plugin-typstyle](https://github.com/kachick/dprint-plugin-typstyle).
